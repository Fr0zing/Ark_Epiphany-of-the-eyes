# ARK Tracker Reborn

Редактируемая read-only версия трекера, восстановленная из исходной .NET-сборки.

## Что изменено

- исходный `ArkTracker.exe` и папка `bin\Dashboard4` не перезаписываются;
- массивы уровней и акторов читаются блоками вместо отдельного системного вызова для каждого указателя;
- малые чтения используют повторно используемые thread-local буферы;
- данные камеры собираются независимым низколатентным контуром с целевой частотой 120 Гц;
- полный снимок акторов и отрисовка больше не блокируют друг друга;
- overlay кэширует отфильтрованный и отсортированный список объектов;
- уменьшено количество временных GDI-объектов при отрисовке;
- панель получила обновлённую тёмную тему и живую телеметрию времени сбора;
- основной overlay перенесён в нативную `ArkOverlayNative.dll`;
- Direct3D 11, Direct2D, DirectWrite и DirectComposition обеспечивают GPU-отрисовку с прозрачностью;
- нативное окно полностью click-through и перерисовывается по новым данным камеры без очереди кадров;
- при невозможности запустить GPU-overlay автоматически используется прежний GDI+ fallback.
- `Insert` скрывает и возвращает панель без переключения фокуса игры;
- большая кнопка `ESP ВКЛ/ВЫКЛ` доступна в верхней части панели;
- фильтрация работает по понятным режимам: все, враги, свои и одно или несколько выбранных племён;
- ники, названия племён, здоровье, сон, смерть и оружие читаются по полям из PDB текущей сборки ASE;
- погибших можно скрыть или показывать отдельным оформлением и ограничить дальность отображения тел;
- для игроков доступны угловая/2D-рамка, скелет, имя, оружие, здоровье и название племени;
- здоровье отображается вертикальной полосой и значением `HP текущее / максимальное`; цвет и толщина полосы настраиваются отдельно;
- рамки игроков вычисляются по живому скелету; фундаменты и другие постройки одного типа/племени группируются по фиксированному мировому расстоянию, поэтому количество не меняется от движения камеры;
- постройки разделены на редактируемые цветные категории; для каждой независимо настраиваются видимость, отдельные точки/группировка и подписи;
- добавлены адаптивный масштаб, оформление текста, устранение пересечений, отдельные дистанции категорий, стрелки за экраном, статусы и направление движения;
- индикатор угрозы показывает число врагов в заданном радиусе и дистанцию до ближайшего;
- четыре готовых профиля, глобальные F6–F9/F11, лимит 0–360 FPS и телеметрия чтения/UI/GPU доступны на странице «Визуал»;
- кости скелета сопоставляются по именам из живого `USkeletalMesh`, а не по ненадёжным фиксированным номерам;
- цвета своих, врагов, выбранных племён и погибших настраиваются отдельно;
- камера передаётся в нативный overlay напрямую с фонового контура около 250 Гц;
- swap chain работает с одним кадром очереди и немедленной подачей в DirectComposition.

Полный список акторов по умолчанию обновляется каждые 8 мс. Позиции игроков и их скелеты передаются в нативный overlay прямо из фонового контура, не ожидая 16-мс таймер интерфейса. Если чтение карты занимает дольше, следующий снимок начинается сразу после завершения предыдущего; камера при этом продолжает обновляться независимо.

Запись в память игры, DLL-инжект и драйверы не используются.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build-reborn.ps1 -Configuration Release
.\bin\Reborn\ArkTracker.Reborn.exe --self-test
```

## Запуск

Запустите `Start-ARK-Reborn.cmd`. Лаунчер запросит повышение прав через стандартное окно UAC, поскольку запущенный экземпляр ASE в текущей конфигурации недоступен процессу среднего уровня целостности.

Если сама игра запущена без повышения прав, можно запустить EXE напрямую:

```powershell
.\bin\Reborn\ArkTracker.Reborn.exe --radar --overlay --wait
```

Сборка использует .NET Framework 4.8 для панели и MSVC/Windows SDK для нативного overlay. NuGet и сторонние runtime-библиотеки не требуются.

Используйте только ASE без BattlEye в своей локальной/частной среде. Проект не пытается обходить защиту игры.

Результат содержит два файла, которые должны находиться рядом:

- `ArkTracker.Reborn.exe` — read-only сбор данных и панель управления;
- `ArkOverlayNative.dll` — GPU-отрисовка внутри процесса трекера, не игры.
